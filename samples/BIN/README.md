# BIN Sample Files

These example files use the observed EE37 format targeted by this project. Hardware support is experimental; see the main README for compatibility details.

Current samples:

- `LaughingMan.bin`
- `Umbrella.bin`
- `arasaka.bin`
- `controller.bin`
- `ghostbusters.bin`
- `jurassicPark.bin`
- `moxes.bin`
- `samurai.bin`
- `weyland.bin`

Where a matching source MP4 is available, it belongs in [`../MP4/`](../MP4/).
